# 安全与隐私

## 一、基本策略

PKAS 采用本地优先、最小权限、来源可追溯和写入可确认的治理方式。

## 二、资料边界

- 每次导入前确认精确来源路径、数据类型、时间范围和用途。
- 不进行未经确认的全盘扫描。
- 原始资料默认只读保存，解析和索引输出进入独立目录。
- 微信及其他聊天中的第三方内容默认标记为 restricted。
- 外部云服务、账号和连接器分别授权，不因本地文件权限而自动获得外部访问权。

## 三、秘密与高敏感数据

知识库不保存密码、访问令牌、私钥、助记词、恢复码和生产密钥原文。需要保留关系时，仅记录秘密所在的受控位置、用途、负责人和轮换要求。

数据库备份、客户资料、身份信息、财务信息、健康信息和私人通信按 restricted 管理，并在进入普通检索或蒸馏前进行单独审核。

## 四、Agent 权限

- 默认允许只读检索和分析。
- 新增长期知识写入 candidate 区。
- 修改正式知识、提升个人特征、生成蒸馏训练集、删除资料、外部发送和发布需要明确确认。
- 每次 Agent 运行记录所用资料、工具调用、写入内容和验证结果。
- 高影响流程支持停止、恢复和人工接管。

## 五、自我蒸馏边界

- 全量资料可以保留在原始层，蒸馏数据只使用经过筛选的内容。
- AI 回答不能因为被保存就成为用户观点。
- 他人隐私不作为用户人格训练内容。
- 情绪状态与稳定性格分开记录。
- 蒸馏数据保留证据、质量分、批准状态和训练或评估分区。

## 六、备份与恢复

后续建立版本化备份、完整性校验、恢复演练和删除审计。原始资料、索引和派生知识采用独立恢复策略，避免索引损坏影响源文件。
