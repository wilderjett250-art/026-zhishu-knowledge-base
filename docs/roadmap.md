# 阶段路线图

## 阶段 0：项目基础

交付内容：

- 项目总纲。
- 分层架构。
- 数据模型。
- 安全与隐私规则。
- 项目工作规则。
- 阶段验收标准。

验收重点：项目边界清楚，原始资料、正式知识、自我模型和蒸馏数据职责不混淆。

## 阶段 1：本地知识底座

交付内容：

- 目录和配置规范。
- 来源登记、哈希、去重和清单。
- Markdown、TXT 和基础文件元数据导入。
- 本地全文检索。
- 工作、自我、共享和蒸馏域过滤。
- 来源引用和权限过滤测试。

验收重点：导入源保持完整，重复资料可识别，检索结果能够定位原文。

## 阶段 2：Codex 检索接入

交付内容：

- 本地 MCP 服务。
- 搜索、读取、主题浏览、候选保存和来源解释工具。
- 项目级 Skill 与调用规则。
- 新线程检索验收场景。

验收重点：Codex 能按任务范围获取资料，不需要加载整个知识库。

## 阶段 3：多格式与资料连接

交付内容：

- PDF、DOCX、表格、网页、图片 OCR、音频转写和代码仓库适配器。
- 聊天导出标准格式。
- 微信资料接入方案和样本验证。
- 增量同步和解析版本管理。

验收重点：每类资料都有合法可读来源、稳定解析结果和隐私分类。

## 阶段 4：工作流系统

交付内容：

- 资料导入工作流。
- 项目分析工作流。
- 技术研究工作流。
- 学习辅导工作流。
- 对话整理与每周复盘工作流。
- 蒸馏候选生成和批准工作流。

验收重点：工作流输入、输出、状态、验证、重试和人工确认可追踪。

## 阶段 5：Agent 系统

交付内容：

- 总控 Agent。
- 任务分类和知识域路由。
- 工具与工作流选择。
- 上下文预算和权限策略。
- 执行日志、确认门和结果评估。

验收重点：Agent 在真实任务中选择正确资料和流程，高影响操作停在确认点。

## 阶段 6：自我模型与蒸馏

交付内容：

- 个人事实、偏好、表达、决策和学习轨迹模型。
- 证据聚合、反例、时间变化和用户确认机制。
- 问答、纠正、偏好对、决策、风格和评估数据导出。
- 个人行为一致性评估集。

验收重点：长期结论有证据和确认，训练样本与评估样本分开，敏感内容通过审核。

## 阶段 7：运维与扩展

交付内容：

- 管理界面。
- 备份、恢复、监控和质量报告。
- 外部连接器和自动化任务。
- 多 Agent 分工与长期任务。
- 模型微调或本地模型适配评估。

验收重点：系统可长期维护、可恢复、可审计，并能以真实指标判断检索和 Agent 质量。
