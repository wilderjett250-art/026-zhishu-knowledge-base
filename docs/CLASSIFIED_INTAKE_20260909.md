## 交付范围

现有 EXE 使用 localhost:8765 页面，资料底座新增分类接入；沿用既有原生壳，无需另建应用。
输入本地目录 → 按五类选择处理方式 → 有界预览 → 明确确认 → 后台处理与结果台账。
当前输入绝对路径，尚无原生目录选择器。每个目录独立选择策略，最近20次操作可查看并恢复。
不注册同步根、不启用开机任务、不启动向量/Agent/WeFlow；不自动采集本任务。

## 各模式的真实含义

| 模式 | 实现 |
|---|---|
| 原文入库 | 本地原生解析、typed切片、全文索引；vault_path引用原路径，metadata.storage_mode=reference。不复制原件。向量outbox由既有触发器排队，不消费。 |
| 本地摘录 | 读取正文，规则抽取最多12段各450字符，生成MD并入库；不是AI语义总结。含原路径、SHA256、生成时间、partial/unreviewed标记及文字警告。 |
| 只收MD | 该类中只接收.md，其他排除。 |
| 收MD，没有则生成 | 以选定目录为范围；若有未排除MD则接入MD、其他登记；没有则生成文件清单MD，不推断项目功能。 |
| 登记位置 | 文件元信息保存在分类接入任务台账，正文/向量不入库；可从任务历史查看，不混入正文搜索。 |
| 不接入 | 不读取正文、不入内容索引；预览中显示排除状态。 |

AI语义摘要未接入，不将摘录冒充AI总结。原件搬家自动重联、全盘后台连续扫描、索引体积/模型费用精确估算仍未实现。

## 边界与恢复

- 预览最多2000文件（API上限10000）、30000遍历项、30秒；超限或权限错误时阻止确认，不把部分结果称全盘完成。
- 系统/缓存/依赖、密钥名称、符号链接及junction、知识库自身数据排除；仅本地绝对目录。无远端文档处理。
- 单文件内容处理20MB上限；内容凭据模式预检仅为启发式，不能保证识别所有秘密。
- 确认后再次核对路径边界、大小、mtime及读取前后hash；改变则失败提示重新预览。
- 有内容写入时先在线备份SQLite，quick_check成功且连接关闭后才发布恢复点；空间预留不足则不入库。
- 资料写入沿用SQLite事务，sources/documents/blocks/messages/chunks/全文索引/audit以及outbox触发器；新版来源成功后标旧版superseded。仍不是跨整个批次的单一事务。
- 批次JSON原子更新；取消在当前文件之后生效，不删除已完成项；中断需再次确认才继续；重复hash复用索引，不覆盖已有原件副本。
- 分类接入本功能的成功批次恢复点：新批成功、当前hash重新验证后，仅删除路径/manifest/hash均匹配的旧成功批次pkas.sqlite，保留最新；异常批次冻结，其余项目备份不动。
- 源文件引用的新版本不会由旧版reindex误写：重建前后均核对来源hash。文件原路径失效仍需人工重新选定目录。
- 旧导入入口仍保留复制行为，本次没有把所有旧连接器迁移，也没有删除旧原件副本。
