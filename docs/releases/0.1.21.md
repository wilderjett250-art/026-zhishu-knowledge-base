# 知域 0.1.21 · 定时同步与安装版补齐

## 本次变化

- 保留每天 00:00 的同步。错过一天时，登录检查会按 Windows 开机时长安排一次补跑；已经成功检查的当天不重复导入，不用常驻轮询。
- 每轮导出、导入、进度保存和失败回执使用同一轮标识。确认没有新消息也能完成检查；失败、部分成功或回执保存异常不会被记成“今天已完成”。
- 失败摘要保留环节、固定原因、数量和处理建议，运行状态页可查看最近异常。精简记录不保存聊天正文、问题、密钥或异常原文；历史有数量上限，不按运行次数无限新增日志文件。
- 数据盘低于 2 GiB 时，在打开数据库、启动 WeFlow 前停止。托管导出只处理文本 XLSX；清理仅针对已经入库且哈希校验通过的旧托管副本，保留至少七天及每会话最近两份，不动用户原导出目录。
- 安装包包含完整的定时任务、一次性补跑、诊断和授权检查脚本。安装版定位自己的 Python 与内置 Node，不再依赖开发者机器的路径；源代码与辅助脚本均纳入运行资源指纹。
- 提供安装版定时更新配置入口，默认只读；启用/停用必须明确授权，拒绝覆盖另一份安装的任务，设置恢复点不复制大型数据库。

## 安装与范围

Windows 10/11 x64，安装后第一次打开需要联网准备运行环境。升级不附带、覆盖或上传个人知识库；原文件、聊天数据和本机密钥不属于发布内容。启用步骤见[定时同步](../scheduled-sync.md)。

WeFlow 是独立工具，没有打包进知域。已有本机自动导出配置可以继续使用；其他用户不能仅凭安装知域就获得微信数据库读取能力。普通导出文件导入与已有授权的自动导出链路是两回事。

安装包仍未签名。本版不宣称已完成另一台实体电脑上的验收，也不把源码测试等同于真实重启、新增消息和云端模型的现场结果。

## 本版验证

- 133 项同步、异常诊断、安装版路径与相关回归测试通过；Rust 7 项单元测试通过。
- 前端生产构建、Windows PowerShell 5.1 脚本语法检查和安装包构建通过。
- 打包与安装后的 11 份辅助脚本哈希逐项相符，85 份 Python 文件与本次源码相符；包内未发现个人数据库、导出表格、密钥、日志或本机交接文件。
- 当前电脑已从 0.1.20 静默升级到 0.1.21，桌面快捷方式指向升级后的 EXE；本次未启动个人资料同步。
