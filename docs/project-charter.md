# 项目总纲

## 一、项目定位

PKAS 是一个面向个人长期使用的知识与智能协作系统。它以统一知识库保存资料，以检索系统为 Codex 和其他入口提供上下文，以工作流完成稳定任务，以 Agent 处理开放任务，并通过用户反馈形成可审计的自我模型和蒸馏数据。

## 二、核心问题

- 个人资料分散在项目目录、聊天、文档、网页、代码仓库和不同应用中。
- 新线程缺少历史上下文，需要反复人工输入。
- 原始资料、AI 总结、个人观点和已验证事实容易混在一起。
- 重要工作经验和用户修正没有稳定进入可检索的长期资产。
- 对用户性格、偏好和决策方式的归纳缺乏证据、时间和确认状态。

## 三、目标用户旅程

1. 用户在 Codex 新线程中提出工作、研究、学习或个人问题。
2. 系统识别问题领域和所需资料范围。
3. 检索层返回少量相关内容及其来源，不加载整个知识库。
4. 工作流或 Agent 完成分析、执行和验证。
5. 系统输出带来源的结果，并记录执行证据。
6. 用户的修正和认可形成候选知识或蒸馏样本。
7. 经过确认的长期内容进入正式知识、自我模型或蒸馏数据集。

## 四、产品范围

### 知识与资料

- 本地文档、代码、项目记录、网页存档、图片、音频和视频。
- 微信及其他聊天记录的合法可读导出。
- Codex 和其他 AI 对话的授权导出。
- 工作知识、业务逻辑、项目决策、学习资料和个人经历。

### 智能能力

- 全文检索、语义检索、过滤、引用和关联发现。
- 资料导入、去重、分类、摘要、研究、学习和复盘工作流。
- 任务路由、工具选择、状态管理、验证和确认机制。
- 个人事实、偏好、表达、决策和学习轨迹的候选提炼。
- 面向未来个人提示词、Skill、RAG、微调和评估的数据导出。

## 五、边界

- 知识库不是密码库，不保存凭证和密钥原文。
- Agent 不默认拥有全部写权限或外部发布权限。
- 原始聊天可以归档，但他人隐私默认限制普通检索和蒸馏。
- AI 生成内容默认属于候选内容，经过证据核对和确认后才能成为正式知识。
- 模型训练属于后期能力，知识质量、检索可靠性和评估体系优先建设。

## 六、成功标准

- 新线程能够按需找到相关历史资料，且无需用户重复粘贴。
- 检索结果带有可定位的来源、时间和权限信息。
- 原始资料保持完整，派生内容与原文分离。
- 工作流具备明确输入、输出、状态、验证和失败处理。
- Agent 的关键工具调用和写入行为可追踪、可复核、可停止。
- 自我模型中的长期结论具有多次证据、时间范围和用户确认。
- 蒸馏数据可按统一格式导出，并有独立评估集验证质量。
