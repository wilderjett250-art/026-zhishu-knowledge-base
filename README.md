# 知枢：个人知识库

知枢想做一件直接的事：让散落在电脑、文档、笔记和聊天记录里的个人资料，能够被 Codex 和其他 AI 应用准确找到、引用和追溯。

它不是把所有文件复制到一个新目录。系统保留原文件，只建立可恢复的索引，并把检索分成三条独立通道：

- **A：精确检索**——按文件名、路径和正文关键词查找。
- **B：语义检索**——通过向量找到意思相近的内容。
- **AB：混合检索**——融合两路结果，兼顾准确匹配和自然语言理解。

## 想解决的问题

- 指定硬盘或目录后，快速建立个人资料地图。
- 分别处理 Word、PDF、Excel、代码、图片和聊天记录。
- 接入 Obsidian 等个人笔记目录。
- 在用户主动授权后接入微信等聊天导出数据。
- 让 Codex、Claude Code及其他支持 MCP 或本地 API 的客户端共用同一套检索结果。
- 每条结果保留来源路径，找不到或证据不足时明确提示。

## 当前公开内容

这是第一批公开内测框架，先提供：

- A/B/AB 检索契约；
- 多通道结果融合核心；
- 整体架构和迭代边界；
- 不依赖个人数据的基础测试。

文档解析、桌面管理台、向量数据库适配和不同客户端连接器会分批整理后推送。微信接入只处理用户自行授权并导出的数据，不包含微信数据库、密钥或绕过平台安全机制的代码。

## 数据边界

仓库不包含个人文件、聊天记录、数据库、向量、API密钥、本机路径、日志或运行缓存。实际数据默认留在使用者自己的电脑上。
