# 个人知识与智能协作系统

英文名称：Personal Knowledge & Agent System（PKAS）

本项目建设一个以个人总知识库为底座、以工作流为骨架、以 Agent 为执行层、以自我蒸馏为长期学习机制的本地优先系统。

## 项目目标

- 统一保存和索引与用户有关的业务资料、工作经验、聊天记录、学习材料和个人资料。
- 让 Codex 在新线程中按需检索相关内容，减少重复输入。
- 通过可验证的工作流处理资料导入、研究、学习、复盘和知识沉淀。
- 在权限和确认机制约束下，让 Agent 动态选择资料、工具和执行路径。
- 从长期对话、决策、修正和认可结果中形成可追溯的个人模型与蒸馏数据。

## 核心原则

1. 一个逻辑知识库，内部按原始资料、正式知识、个人模型、蒸馏数据和索引分层。
2. 本地优先，外部服务按需连接并单独授权。
3. 原始资料保持可追溯，不被摘要或整理结果覆盖。
4. 派生结论必须保留来源、时间、可信度和确认状态。
5. 读取和检索可以自动执行，长期写入和高影响操作设置确认门。
6. 固定工作优先使用可测试的工作流，复杂开放任务再由 Agent 动态处理。
7. 全量资料可以归档，进入蒸馏数据集的内容必须经过筛选、脱敏和质量评估。

## 当前阶段

当前阶段建立项目总纲、数据边界、系统架构、治理规则和路线图。真实个人资料将在完成来源盘点、权限分类和导入验收后分批接入。
