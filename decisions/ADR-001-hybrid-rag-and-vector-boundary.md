# ADR-001：混合 RAG 与向量边界

- 状态：已接受
- 日期：2026-08-28

## 决策

PKAS 保留 SQLite + FTS5 精确全文检索，增加 Qdrant 语义索引，并通过独立检索层执行混合召回。Embedding 由可替换的云端提供方生成；首个适配器使用 SiliconFlow 的 OpenAI 兼容 `/v1/embeddings` 接口，默认模型为 `BAAI/bge-m3`。

## 原因

- 中文业务资料同时包含精确名称、型号、路径和自然语言描述，单一检索方式不足。
- 用户电脑不部署本地模型，Embedding 计算需要云端 API。
- Qdrant 索引可复制、可重建，且不会取代本地原文和 SQLite 证据链。
- 提供方、模型和向量维度必须版本化，避免换模型后混用旧向量。

## 约束与后果

- 密钥只从进程环境或本机安全配置读取，不能进入源码、数据库、日志或知识库。
- 只处理新增或内容哈希变化的片段；查询时仅向量化当前查询。
- `restricted` 资料远程向量化默认关闭。
- Qdrant 不可用、密钥缺失或索引覆盖不足时，全文检索继续工作并返回降级原因。
- 模型切换需要重建可再生的向量索引，不修改原始资料。
